# somehow

Public pages and downloads for the iOS game **somehow: a life, probably**.

- `privacy/`: privacy policy (EN/DE/ES), App Store privacy URL: https://nikname1998.github.io/somehow/privacy/
- `support/`: support page (EN/DE/ES), App Store support URL: https://nikname1998.github.io/somehow/support/
- Releases: read-aloud voice files (tag `voices-v1`), with their licence texts.

Questions and bug reports: [Issues](https://github.com/nikname1998/somehow/issues).
The game's source lives in a private repository.
